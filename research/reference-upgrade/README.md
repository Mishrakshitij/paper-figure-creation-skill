# Reference-driven design revision

The user rejected the first gallery as visually insufficient and supplied five concrete references. This revision treats that feedback as a design failure to address. The original evidence validator and export checks remain useful, but passing them did not demonstrate the desired quality of visual explanation.

This is ten figure assets plus an algorithm image across all five papers. Repository/project-page assets may differ from later PDF revisions. Source versions and failed retrievals are recorded in the linked reviews; full PDFs and unavailable figures are not counted as visually inspected. Original artwork is linked, not redistributed.

## What changes in the skill

The revised workflow makes representation design an explicit deliverable before final geometry: identify the relevant objects, choose which internal details matter, preserve one example across states, and locate the novel operation. Composition follows that argument. A theme controls typography, role colors and line weights; it does not dictate a universal row of boxes.

For teasers, the concept should teach the task or measurement used by the evidence region. For methods, branches, state changes, repeated instances and merges should be visible where scientifically relevant. The user's approximate 35:65 concept/evidence preference remains a starting point. The inspected radial overview is a reference for hierarchy, not a mandate to use radial charts.

The [new examples and review](../../docs/design-upgrade.md) exercise these choices. The MAE comparison uses the same paper as an existing example; SEAL and WMRL exercise different structures. These are guided design iterations, not a controlled benchmark or proof of universal superiority. The old images remain available so the visual difference can be assessed directly.
