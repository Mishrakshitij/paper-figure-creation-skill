The new skill must work when copied by itself, without another skill or this repository's example paths.

4. Demonstrate the routes using all eight reported LoRA settings, all SEAL knowledge conditions, a composed SEAL teaser, and the existing method/setup gallery. Keep unfavorable results visible. Do not fabricate uncertainty.
5. Inspect actual PDF/PNG pixels and physical text sizes; independently test routing and scientific comprehension. Repair observed defects, record limitations, and verify exports before installation and publication.

## Acceptance criteria

- README explains which workflow to load and what command to run; no history-first navigation.
- New skill contains the user's nine standing principles and automatically applies to paper diagrams, illustrations, graphical abstracts, figure improvements, and graphs.
- Standalone graphs are a first-class job. No numeric marks are generated by an image model.
- Hybrid assembly is reproducible, self-contained, and preserves editable text/paths. Raster assets are explicitly illustrative, with prompts, source, rights status, and effective resolution.
- Physical type size survives importing a chart into a larger canvas. Point/pixel confusion cannot silently shrink labels.
- Benchmark figures remain conditional on a substantive setup; result tables alone never trigger them.
- One canonical geometry source per figure; PDF/SVG/PNG exports are checked, and unsupported native formats are stated.
- Existing numerical/benchmark validation tests pass; added tests cover concrete new risks.
- Research records distinguish inspected source code, viewed pixels, and uninspected material. No claim of hundreds of full figure reviews or measured superiority.

## Demonstration composition decision

For the SEAL teaser consider: (A) vertical conceptual scene beside aligned condition plots; (B) a long horizontal pipeline above a full-width comparison; (C) a central adaptation loop surrounded by result insets. Select A: it preserves 35:65 concept/evidence, keeps all conditions equally visible, and avoids crossing the evidence area with the reward-training loop. The method loop belongs in its own method figure.

Generated imagery is limited to a text-free notebook asset behind editable passage text. The passage and derived statements are explicitly constructed examples. Source-grounded graph panels remain independently rebuildable. This is an illustration of the hybrid workflow, not evidence that image generation alone improves scientific communication.
