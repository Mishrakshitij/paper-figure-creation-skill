# Existing skills and preferences

This front door builds on two complementary sources:

- **paper-figure-creation:** retained in this repository and bundled under `foundation/`, including evidence, setup eligibility, visual-story primitives, and reproducible rendering. Its instructions are preserved; the new router adds explicit planning, standalone graphs, and hybrid assembly.
- **codex-paper-figure-skill:** the user's cited [upstream](https://github.com/pengqianhan/codex-paper-figure-skill) informs dependency-graph-first planning and editable native diagram reconstruction. No third-party implementation or generated artwork is copied into this skill.

If a named companion is installed, read its relevant instructions and existing user customizations before using it. Do not overwrite it or require the user to reinstall it. Use the current user request and project instructions to resolve routine choices. Preserve accepted notation, colors, export conventions, and previously correct scientific structure.

Use an installed native draw.io workflow when the user needs interactive diagram editing. Use bundled vector/plot tools when exact geometry or graph composition is clearer. Keep the same scientific contract and one canonical geometry source across either route. Do not route a precise quantitative graph through whole-image generation.

The bundle is self-contained so a missing companion does not block ordinary work. If a requested companion-specific capability is absent, state that limitation and use the supported route where it fulfills the task.
