[Vector PDF](wmrl-method.pdf) · [Editable SVG](wmrl-method.svg) · [Caption and alt text](caption.md) · [Design brief](brief.md) · [Review](review.md)

Rebuild with `python examples/wmrl/build_figure.py` from the repository root. Dependencies are Matplotlib and Pillow. `build_figure.py` is the canonical geometry source; the SVG preserves ordinary text as editable text. The outputs have a fixed physical size of 7 × 3.92 inches. This custom figure does not use the starter JSON layout engine or provide a native draw.io file.

The reference paper and author image were used to understand scientific structure and design choices. This example contains original vector geometry and no copied author image assets. The task/code are illustrative, and there is no fabricated performance chart. This is a guided design exercise, with no measured claim of skill superiority.
