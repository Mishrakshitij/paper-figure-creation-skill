# SEAL figure brief

Target: an original 7-inch two-column draft. Venue and manuscript placement are unspecified. Teaser height 4.8 inches; method height 5.35 inches. Final venue fitting remains necessary.

The visual claim: the model learns to prepare useful training material, then uses it to change its weights. The teaser should make that distinction understandable through a concrete example; the method should reveal the candidate evaluation loop.

The author-provided Figure 1 and domain diagrams were inspected as pixels. Transferable principles: repeat parameter identities, give generated data its own visual form, fan candidate branches from one current model, separate adaptation from evaluation, and make the reward return visible. The redraw does not reuse or trace the source artwork.

Teaser alternatives considered (the visual comparison sheet was created after the initial draft, as a late design comparison):

- A, selected: a vertical example occupies approximately 34% of content width; an aligned dot-table keeps every method and passage regime visible, with a compact ARC comparison below.
- B, rejected: a full-width example ribbon above four independent charts. The ribbon repeated the headline and left less room for method labels and full-source comparisons.

Method alternatives considered:

- A, selected: three candidate lanes above two concrete representation insets. This preserves independent updates from the same starting weights.
- B, rejected: a circular four-stage workflow around a large model icon. It hides candidate identity and can suggest that each trial starts from the preceding adapted model.

The fictional Lyra passage, rewritten notes, and example grid transformation are teaching schematics, not recorded model outputs. Experimental results are reported Table 1–2 values from arXiv v2, with no invented uncertainty. The project website has stale continued-pretraining numbers; its prose was not used as numerical evidence.
