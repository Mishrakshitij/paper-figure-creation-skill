**Masked autoencoder pretraining with a synthetic teaching image.** The input is divided into sixteen patches; a random subset of twelve is masked, leaving patches 2, 6, 11 and 15. Only the four visible patch tokens, shown in a shuffled order with their original position identities, enter the encoder. The visible representations are projected for the decoder and combined with twelve copies of a shared learned mask token. Unshuffling restores the original positions, after which decoder position embeddings are added. A lightweight decoder predicts patch pixels at all sixteen positions; each symbolic output slot represents the pixels of one image patch, and MSE is evaluated only at the twelve positions masked at input, indicated by solid corner marks on the output slots, using targets from the original image. The generated fox scene is an illustrative input, not a dataset example or an empirical reconstruction. Output slots are symbolic and no model was run. Model-stack depths are schematic. Patch projections, the CLS token and internal attention operations are omitted. Based on [He et al., Section 3 and Figure 1](https://arxiv.org/pdf/2111.06377v3) and the [official implementation](https://github.com/facebookresearch/mae/blob/main/models_mae.py).

A smaller decoder outputs sixteen symbolic pixel-prediction slots. Twelve slots have solid corner marks for a masked-only MSE loss, which also receives the original image pixels from the corresponding twelve masked locations.
